# v1 finite element evidence

This directory contains genuinely executed CalculiX 2.23 analyses of the reconstructed v1 CAD. Values from the old v0 report are not used as v1 solver results.

## Run modes

- `python3 scripts/run_fem.py --force` rebuilds the Gmsh STL/volume meshes and executes all 20 configured solver cases.
- `python3 scripts/run_fem.py --audit` verifies current input/output hashes, reloads the configured per-mesh summaries and recomputes acceptance checks. It reparses the complete retained finest-mesh fields and recomputes the combined stress bounds. Coarser convergence metrics use the explicitly retained, hash-protected executed-run evidence.
- A development subset such as `--part bracket --size 6 --cases fx --skip-stl` is explicitly incomplete and cannot pass the project acceptance audit.

Each mesh folder has a shared `common_mesh.inc.xz`, per-case `.inp.xz` decks, actual `.solver.log` text, per-case JSON metrics, and a combined `summary.json`. The shared include stores nodes, elements, material and boundary conditions. Each small case deck includes that file and adds its own loads and output requests.

## Lossless compression and retained fields

Full `.frd.xz` and `.dat.xz` fields are retained for the finest bracket mesh and finest beam mesh. `retained_evidence.json` records which coarser raw field files were omitted as regenerable output, including their actual compressed and decompressed SHA-256 values. All coarse input decks, meshes, successful solver logs, per-case metrics, mesh-quality records, reactions and stress-envelope metrics remain. This keeps the version ZIP practical to download without removing the refinement study. Run `--force` to regenerate every omitted field.

XZ compression is lossless and uses Python's standard `lzma` module. To inspect one retained case, decompress its `.inp.xz`, `.frd.xz`, `.dat.xz` and the shared `common_mesh.inc.xz` into a separate working directory. Running `ccx -i CASE` there reproduces that case. The project runner performs this preparation automatically in isolated temporary directories.

## Model and result interpretation

The bracket model includes the root fillet and tapered reinforcement. Sacrificial ribs and interference preload carry no credited structural load. Six independent linear cases are applied at the plug tip: three 20 N force axes, 550 N mm torsion, and two 1600 N mm transverse moments. Force and moment resultants are balanced exactly. The conservative direction bound is the Euclidean norm of the three force-case scalar measures, plus the torsion-case measure, plus the Euclidean norm of the two transverse-moment measures. Both von Mises stress and maximum absolute principal stress use this bound at nodes and integration points. The principal measure is the spectral norm of the symmetric stress tensor, not the Frobenius norm.

Y/Z translations are restrained on sleeve bores. X translations are restrained on the wall and washer bearing annuli at x=0 and x=7.8, from radius 9.3 to 14.35 mm, using the minimum specified 28.7 mm washer outside diameter. These are bilateral, already-engaged idealizations. The actual washer gap, load take-up, friction, sleeve preload and opening contact are unqualified.

The beam volume is generated by sweeping the actual imported STEP end face along its 400 mm length. The swept exact CAD volume is checked against the imported volume. Linear geometric tetrahedra receive quadratic C3D10 displacement nodes; their geometric volume is measured independently and compared with the exact CAD volume. An exact 10 by 10 mm top-face pressure patch is integrated by clipping the surface triangles and integrating their quadratic shape functions. This remains accurate when a mesh triangle crosses the pressure-patch boundary. The global section-average deflection is compared with Euler beam theory; the local maximum is retained separately.

CalculiX's RF field contains reaction plus applied nodal loads. The reaction extraction subtracts concentrated loads and consistent gravity loads from RF at restrained degrees of freedom. For a straight tetra10 under constant gravity, each corner shape function integrates to -V/20 and each midside shape function to V/5. Their total force and moment are independently tested. Gravity uses the actual FE volume and centroid, not an artificially substituted CAD mass.

The Gmsh tetra10 ordering is mapped to CalculiX by exchanging the final two midside nodes. DAT shear components are reordered from XY/XZ/YZ to XY/YZ/ZX before tensor operations. Raw node and integration-point maxima remain in the numerical checks. No peak is removed to make a convergence test pass.

A successful solver run is not proof that the assembly meets the 10 N requirement. Material screens, geometric accuracy, equilibrium, mesh convergence, physical fit, printed material and the real wall installation have separate acceptance gates.
